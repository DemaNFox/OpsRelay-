# Roadmap

## v0: MVP

```text
- server API;
- admin CLI;
- Go client-agent;
- device enrollment;
- heartbeat;
- shell.exec;
- debug sessions;
- local session artifacts;
- reboot with confirmation;
- audit log;
- Windows and Ubuntu support baseline.
```

## v0.1: Hardening

```text
- stronger device identity;
- token rotation;
- device revoke;
- improved policy engine;
- output object storage;
- better CLI UX;
- CI pipeline;
- package signing research.
```

## v0.2: Diagnostics Presets

```text
- Windows printer preset;
- Windows network preset;
- Linux service preset;
- Linux package/service health preset;
- session report generator.
```

## v0.3: Web UI

```text
- device list;
- device details;
- online/offline status;
- session viewer;
- job history;
- audit viewer;
- approval prompts.
```

## v0.4: Files and Logs

```text
- file.get;
- file.put with approval;
- Windows Event Log adapter;
- journald adapter;
- log query API.
```

## v0.5: Policies and Approvals

```text
- command classification;
- risk levels;
- approval UI;
- per-device/group policies;
- role-based permissions.
```

## v1.0: Production Ready

```text
- SSO/2FA;
- multi-tenant organizations;
- signed agents/installers;
- auto-update;
- advanced RBAC;
- high availability server deployment;
- observability dashboards;
- compliance/audit export.
```

## Possible Later Features

```text
- interactive terminal;
- remote desktop integration;
- macOS agent;
- plugin system;
- integrations with ticketing systems;
- AI-generated final reports;
- AI safety policy templates.
```
