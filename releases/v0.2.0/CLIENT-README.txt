OpsRelay Agent v0.2.0 (Windows x64)

1. Open opsrelay-agent-windows-amd64.exe.
2. Enter the server URL and the one-time enrollment token from your administrator.
3. Check the device name and click "Зарегистрировать и подключить".
4. Keep the visible window open while support is connected.

On later launches, the app asks whether to connect using the saved device identity.
The enrollment token is not saved and cannot be reused. Closing the window stops
the client connection. The green status dot means the agent is connected.

Use only on a device whose owner has approved remote support.
